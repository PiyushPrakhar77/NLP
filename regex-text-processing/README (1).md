# Regular Expressions for Text Processing in Python

## Overview
This project demonstrates the use of **Regular Expressions (Regex)** in Python to extract, identify, validate, and normalize text patterns using the built-in `re` module.

## Features
- Extract domain names from URLs.
- Extract email addresses from text.
- Identify hashtags and social media mentions.
- Extract decimal numbers.
- Detect special characters.
- Validate Indian vehicle registration numbers.
- Normalize repeated characters in text.
- Extract Indian mobile phone numbers.
- Identify proper nouns using capitalization patterns.

## Technologies Used
- Python
- `re` (Python's built-in Regular Expression module)

## Installation
No external libraries are required. Python's built-in `re` module is sufficient.

## How to Run
1. Download or clone this repository.
2. Open `S25MCAG0109_Lab1(1).ipynb` in Jupyter Notebook or Google Colab.
3. Run the code cells sequentially.
4. Review the output for each regular expression example.

## Learning Objectives
- Understand regex patterns and special symbols.
- Use functions such as `re.findall()`, `re.match()`, and `re.sub()`.
- Apply pattern matching to practical text-processing tasks.
- Build basic text extraction and validation functions.

## Applications
Regular expressions are useful in data cleaning, text mining, information extraction, form validation, and Natural Language Processing (NLP).

## Limitations
The email, phone number, and vehicle registration patterns are simplified examples. They may not cover every valid real-world format.
